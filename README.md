## 🔍 What is NSystem Intelligence?

NSystem Intelligence is a code analysis platform built to help developers identify potential problems, understand architectural complexity, and improve maintainability across .NET applications.

Whether you're working with a large legacy system or a new project, NSystem Intelligence provides actionable insights into your codebase.

### Key Features

- **Static Code Analysis** — Analyze C# and .NET solutions using Microsoft Roslyn.
- **Code Quality Metrics** — Identify complex methods, maintainability issues, and potential code improvements.
- **Architecture Analysis** — Understand project dependencies, architectural relationships, and structural problems.
- **Architecture Drift Detection** — Compare analysis results against established baselines and detect changes over time.
- **Configurable Quality Thresholds** — Customize analysis thresholds to match your project's requirements.
- **AI-Assisted Insights** — Get explanations and improvement suggestions for identified issues.
- **Local Analysis** — Analyze your source code locally without uploading your entire codebase to a remote server.
- **CLI Integration** — Run analyses from the command line and integrate quality gates into CI/CD pipelines.
- **Baseline Comparison** — Track changes in code quality between analysis runs.

Feature availability may vary depending on the application version and license.

## 🔐 Security and Privacy

NSystem Intelligence follows a local-first approach to code analysis.

- Source code analysis is performed locally.
- Your entire project does not need to be uploaded to a cloud service for static analysis.
- AI-assisted features may communicate with external AI providers depending on your configuration.
- Authentication and licensing functionality may require communication with NSystem Intelligence cloud services.

For sensitive or proprietary projects, review your AI provider settings before enabling AI-assisted functionality.
